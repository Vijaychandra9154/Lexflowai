# Deployment Guide

## Architecture
- **Backend** → Render (Python web service + PostgreSQL)
- **Frontend** → Netlify (Next.js via @netlify/plugin-nextjs)

---

## 1. Deploy Backend to Render

### Steps
1. Push this repo to GitHub.
2. Go to [render.com](https://render.com) → New → **Blueprint** → connect your repo.
3. Render reads `render.yaml` automatically. It will create:
   - `lexflowai-backend` (Python web service)
   - `lexflowai-db` (PostgreSQL free tier)
4. After the service is created, go to **Environment** tab and add:
   - `ANTHROPIC_API_KEY` = `sk-ant-...` (your key from console.anthropic.com)
5. Click **Manual Deploy** → Deploy Latest Commit.
6. Note your backend URL: `https://lexflowai-backend.onrender.com`

### Verify
```
curl https://lexflowai-backend.onrender.com/api/health
# → {"status": "LexFlowAI backend up"}
```

---

## 2. Deploy Frontend to Netlify

### Steps
1. Go to [netlify.com](https://netlify.com) → Add new site → Import from Git.
2. Select your repo, then set:
   - **Base directory**: `frontend`
   - **Build command**: `npm run build`
   - **Publish directory**: `frontend/.next`
3. Under **Environment variables**, add:
   - `NEXT_PUBLIC_BACKEND_URL` = `https://lexflowai-backend.onrender.com`
4. Click **Deploy site**.

### Netlify detects `netlify.toml` automatically
The `@netlify/plugin-nextjs` plugin is declared there — no extra config needed.

---

## 3. Update CORS (after you have the Netlify URL)

Once Netlify gives you a URL like `https://lexflow-ai.netlify.app`, add it to
`backend/app/main.py` in the `allow_origins` list:

```python
allow_origins=[
    "http://localhost:3000",
    "https://lexflow-ai.netlify.app",   # ← add your actual Netlify URL
    "https://*.netlify.app",
],
```

Then redeploy the backend (git push → Render auto-deploys).

## Docker (local full-stack)

```bash
# Copy and fill in your key
cp .env.example .env
# Edit .env: set ANTHROPIC_API_KEY

docker compose up --build
# Backend: http://localhost:8000
# Frontend: http://localhost:3000
```

## Environment Variables Reference

| Variable | Required | Where |
|---|---|---|
| `ANTHROPIC_API_KEY` | ✅ | Render env |
| `DATABASE_URL` | ✅ | Auto-set by Render from DB |
| `JWT_SECRET` | ✅ | Auto-generated by Render |
| `NEXT_PUBLIC_BACKEND_URL` | ✅ | Netlify env |
| `OPENAI_API_KEY` | ❌ optional | Render env (for legacy endpoints) |
